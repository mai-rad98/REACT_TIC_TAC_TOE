# Tic-Tac-Toe Game

A modern, interactive Tic-Tac-Toe game built with React, TypeScript, and Vite. Features a clean UI with confetti animations for winners!

![Tic-Tac-Toe Game](./public/Group%201.png)

## 🎮 Live Demo

Play the game here: [https://ephemeral-blini-925319.netlify.app/](https://ephemeral-blini-925319.netlify.app/)

## ✨ Features

- Interactive 3x3 game board
- Two-player gameplay (X and O)
- Winner detection with confetti animation
- Clean, responsive design
- Built with modern React patterns and TypeScript

## 🛠️ Tech Stack

- **React** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **CSS** - Styling

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`

## 📦 Build

To build for production:

```bash
npm run build
```

## 🎯 How to Play

1. Players take turns clicking on empty squares
2. Player X goes first
3. First player to get 3 in a row (horizontally, vertically, or diagonally) wins
4. Enjoy the confetti celebration when you win!
